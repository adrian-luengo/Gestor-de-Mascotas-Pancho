# Proyecto de Fundamentos de Ingeniería de Software - IWSIM21-02

¡Bienvenido al repositorio del proyecto de Fundamentos de Ingeniería de Software (FIS) del grupo IWSIM21-02!

Este repositorio contiene el código fuente, documentación y recursos relacionados con nuestro proyecto. Aquí encontrarás todo lo necesario para colaborar en el desarrollo, realizar seguimiento del progreso y contribuir al éxito de nuestro proyecto.

## Descripción del Proyecto

El proyecto IWSIM21-02 se centra en desarrollo de la practica de FIS

## Acceso a Redmine

Utilizamos Redmine como nuestra plataforma principal de gestión de proyectos. Puedes acceder a nuestro proyecto en Redmine a través del siguiente enlace: [Redmine IWSIM21-02](https://fis.etsisi.upm.es/projects/upmfis-iwsim21-02)

## Contribución

¡Apreciamos enormemente cualquier contribución al proyecto! Si deseas contribuir, sigue estos pasos:

1. Revisa las [issues abiertas](https://fis.etsisi.upm.es/projects/upmfis-iwsim21-02/issues) en Redmine para encontrar tareas en las que puedas ayudar.

2. Realiza un fork del repositorio y trabaja en tu propia rama de características (`feature-branch`).

3. Una vez completada tu contribución, envía un Pull Request a la rama principal del repositorio.

4. Nuestro equipo revisará tu código y lo fusionará con la rama principal una vez aprobado.
